# UT-Data-Science-Course-Projects
This repository contains the assignments and final project for the Data Science course at the University of Tehran. The work was completed by a student group throughout the semester and demonstrates practical experience with data analysis, visualization, machine learning, and statistical reasoning.

All assignments were implemented in Python and are based on real-world datasets and applied problem-solving. Each assignment focuses on a different core concept in data science, ranging from web scraping and statistical inference to dimensionality reduction, semi-supervised learning, and large language models.

In addition to the assignments, the repository also includes the final course project, which follows the full data science pipeline: data collection, data cleaning, exploratory analysis, feature engineering, regression modeling, and evaluation.

# Assignments

## Assignment 0: Web Scraping and Introductory Data Analysis  
This assignment focused on collecting Ethereum transaction data from Etherscan using web scraping. The workflow included browser automation, HTML parsing, data cleaning, exploratory visualization, and a comparison of population statistics with simple random and stratified samples.

**Topics:** Web scraping, exploratory data analysis, descriptive statistics, sampling  
**Tools:** Python, Selenium, Beautiful Soup, pandas, NumPy, Matplotlib, Seaborn
